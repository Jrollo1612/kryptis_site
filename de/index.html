About the app

Kryptis is a free project that provides tools to translate text to various codes and codes to text. It offers both an online translator and a desktop application that can be used offline. The app is designed to be fast, accurate, and user-friendly, making it easy for anyone to use regardless of their technical expertise. With support for punctuation marks and a visual interface, Kryptis is a versatile tool for anyone interested in code translation.

Why use Kryptis??

Kryptis is a free and open-source project, which means that you can use it without any cost and even contribute to its development if you want.

4 Key Advantages:

No pubs! Kryptis is a free project, which means you can use it without any cost.
Fast and accurate translation The app provides fast and accurate translations between text and Morse code.
Punctuation compatibility Kryptis supports punctuation marks, making it more versatile.
Offline software with visual interface The app can be used offline and features a visual interface.

A view about my history

I began to create the morse translator because I was a scout and it was a project to do to obtain a badge. I did it on my last year of scouting. I choose to update it recently to make it usable for a higher number of codes. Then, I created Kryptis, which is what you know.

What is the morse code?

The morse code is a method of transmitting text information as a series of tones, short and long.
It was invented by Samuel Morse in the 1830s.
