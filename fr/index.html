À propos de mon histoire

J'ai commencé à créer le traducteur morse parce que j'étais un scout et c'était un projet à faire pour obtenir un badge. Je l'ai fait pendant ma dernière année de scoutisme. J'ai choisi de le mettre à jour récemment pour le rendre utilisable pour un plus grand nombre de codes. Ensuite, j'ai créé Kryptis, ce que vous connaissez.

Qu'est-ce que le code morse?

Le code morse est une méthode de transmission d'informations textuelles sous forme de séries de sons, courts et longs.
Il a été inventé par Samuel Morse dans les années 1830.
Le message le plus célèbre était S.O.S: .../---/....
Aujourd'hui, il est encore utilisé chez les Scouts.
